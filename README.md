# VASP Analysis Toolkit

A collection of Python scripts and utilities for analysing and processing computational materials science data, with a particular focus on calculations performed using the Vienna Ab initio Simulation Package (VASP).

## Overview

This repository contains Python-based tools developed to support computational chemistry and materials modelling research. The scripts are designed to assist with the analysis, extraction and processing of data from VASP calculations, helping to streamline common tasks in density functional theory (DFT) workflows.

The toolkit reflects my research experience in computational materials chemistry, particularly in the investigation of catalytic materials, surface chemistry, adsorption processes and reaction energetics.

## Research Applications

The scripts are intended to support computational materials modelling tasks, including:

* **VASP output analysis:** Extracting and processing relevant information from computational output files.
* **DFT data processing:** Organising and analysing results from electronic-structure calculations.
* **Catalyst modelling:** Supporting the investigation of adsorption behaviour and surface properties.
* **Computational workflows:** Automating repetitive tasks associated with atomistic simulations and materials modelling.

The repository is intended to evolve as additional tools and functionalities are developed.

## Technologies

The tools in this repository are primarily developed using:

* **Python** – scripting, data processing and workflow automation.
* **NumPy** – numerical operations and array processing.
* **Matplotlib** – data visualisation.
* **VASP** – electronic-structure calculations and atomistic modelling.

Additional Python packages may be required depending on the individual script.
